✨ Features
📊 Analysis of India's CPI (Consumer Price Index) data across multiple sectors.
🍽️ Category-wise inflation contribution analysis (Food, Housing, Fuel, Education, Healthcare, Transportation, etc.).
📈 Year-over-Year (YoY) inflation trend analysis from 2017 onwards.
📉 Month-over-Month (MoM) inflation growth calculations.
🥗 Food inflation deep-dive and major contributor identification.
🦠 COVID-19 impact assessment on inflation and essential services.
⛽ Oil price fluctuation vs inflation correlation analysis.
🔍 Missing value treatment using imputation techniques.
📊 Interactive visualizations and trend charts.
📚 Research-backed explanation of major inflation spikes.
